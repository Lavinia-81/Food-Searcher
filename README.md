# Food Searcher
Recipe & Meal Finder — HTML • CSS • JavaScript • Public APIs  
Live Demo: https://lavinia-81.github.io/Food-Searcher/

A lightweight web application that allows users to search for meals, explore recipes, and view detailed cooking instructions using a public food API.
This project was created early in my learning journey to experiment with API calls, JSON parsing, dynamic DOM updates, and interactive UI design.

---

## Overview
Food Searcher demonstrates how a front‑end application can communicate with external APIs to fetch real‑time data and display it in a clean, user‑friendly interface.

The app allows users to:
- search for meals by keyword
- view recipe details
- explore ingredients
- display cooking instructions
- load images dynamically from API responses

This project highlights essential front‑end development skills and early API integration experience.

---

## Features
### Search Functionality
- Search meals by name or keyword
- Fetch results from a public food API
- Display meal cards dynamically

### Recipe Details
- Show meal image
- List ingredients
- Display cooking instructions
- Provide category and origin (if available)

### UI & Design
- Responsive layout
- Clean card‑based design
- Smooth dynamic rendering
- Vanilla CSS styling

### JavaScript Logic
- Fetch API requests
- JSON parsing
- Dynamic DOM manipulation
- Error handling for invalid searches
- Loading states (optional depending on implementation)

## How to Use
- Open index.html in your browser.
- Type a food name or ingredient into the search bar.
- Click Search.
- Browse the list of meals returned by the API.
- Click on a meal to view detailed recipe information.
